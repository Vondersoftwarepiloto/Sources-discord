# 💡 Bot de Sugestões

## Funcionalidades
- Comando `/sugerir` para enviar sugestões
- Reações automáticas (👍 👎 ✅ ❌)
- Staff pode aprovar/rejeitar com ✅/❌
- Canal e cargo de aprovação configuráveis

## Instalação
```bash
npm install
cp .env.example .env
node index.js
```

## Comandos
- `/sugerir` - Envia uma sugestão
- `/config canal` - Define canal de sugestões
- `/config cargo` - Define quem pode aprovar
- `/config ver` - Mostra configurações
