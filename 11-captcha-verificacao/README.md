# 🔐 Bot Captcha / Verificação

Sistema de verificação com captcha simples (código aleatório).

## Funcionalidades
- Painel com botão
- Modal com código gerado
- Atribui cargo automaticamente após acertar
- Proteção básica contra bots

## Instalação
```bash
npm install
cp .env.example .env
node index.js
```

## Comandos
- `/captcha painel` - Envia o painel
- `/captcha cargo` - Define o cargo de verificado
