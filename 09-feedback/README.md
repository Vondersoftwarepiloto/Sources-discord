# 🎁 Bot de Feedback com Recompensa

## Funcionalidades
- Envio de feedback com nota (1-5)
- Contagem de feedbacks por usuário
- Cargo de recompensa após X feedbacks
- Canal de feedbacks configurável

## Instalação
```bash
npm install
cp .env.example .env
node index.js
```

## Comandos
- `/feedback enviar` - Envia um feedback
- `/feedback config` - Configura canal, cargo e mínimo
