# 🧩 Bot de Fac (Básico)

Sistema simples de registro de membros + farm semanal.

## Funcionalidades
- Painel de registro de membros
- Painel de farm (contagem semanal)
- Ranking de farm
- Atribui cargo automaticamente no registro (opcional)

## Instalação
```bash
npm install
cp .env.example .env
node index.js
```

## Comandos
- `/painel registro` - Painel de registro
- `/painel farm` - Painel de farm
- `/painel ranking` - Ranking da semana
